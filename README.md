# Корни: семейный архив

Первый локальный прототип семейного архива на чистом HTML, CSS и JavaScript.

## Что уже работает

- интерактивное семейное древо с карточками, связями и hover-описаниями;
- открытие профиля человека с биографией, важными моментами и связанными снимками;
- раздел «Все люди» с поиском и фильтрами;
- семейный альбом с фильтрацией по годам;
- лента времени;
- админ-панель с локальным паролем;
- добавление и редактирование людей;
- загрузка фото с устройства в профиль;
- сохранение правок в `localStorage`.

## Запуск

Откройте `index.html` в браузере. Сервер для этого прототипа не нужен.

Публичный архив: `https://gu-master.github.io/`

Админ-панель: `https://gu-master.github.io/admin.html`

Пароль демо-админки: `family2026`.

Важно: это статический прототип на GitHub Pages. Пароль находится в клиентском JavaScript и не является настоящей серверной защитой. Перед публикацией реальных семейных данных нужно вынести авторизацию, хранение файлов и базу данных на сервер.

5. Подключить резервное копирование и публикацию архива по ссылке.
